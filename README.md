# riscv-crypto-fpga
A modular 32-bit RV32I RISC-V SoC implemented in Verilog with a memory-mapped SHA-256 hardware accelerator, developed on the Xilinx Basys-3 (Artix-7) FPGA. The project emphasizes RTL design, pipelined architecture, verification, FPGA implementation, and hardware/software co-design.
