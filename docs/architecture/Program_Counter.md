# Program Counter (PC) Architecture

## 1. Overview

The Program Counter (PC) is one of the fundamental sequential components of the RV32I processor. It stores the address of the instruction currently being executed and is updated every clock cycle based on the value supplied by the Next Program Counter logic.

The Program Counter itself does not calculate the next instruction address. Instead, it acts as a dedicated register that loads an externally computed address whenever the write enable signal is asserted.

This modular approach simplifies the design and allows the same Program Counter to support sequential execution, branching, jumps, and future pipeline enhancements.

---

# 2. Features

- Parameterized data width
- Synchronous reset
- Synchronous write enable
- External next program counter input
- Pipeline-ready interface
- Synthesizable RTL

---

# 3. Module Interface

| Signal | Direction | Width | Description |
|---------|-----------|------:|-------------|
| clk | Input | 1 | System clock |
| rst | Input | 1 | Active-high synchronous reset |
| pc_write | Input | 1 | Program Counter write enable |
| pc_next | Input | DATA_WIDTH | Next program counter value |
| pc | Output | DATA_WIDTH | Current program counter |

---

# 4. Functional Description

The Program Counter performs one of three actions on every rising clock edge.

### Reset

When `rst` is asserted,

```
PC ← RESET_VECTOR
```

The Program Counter is initialized to the processor reset vector.

---

### Update

When `pc_write` is asserted,

```
PC ← PC_NEXT
```

The externally generated next address is loaded into the Program Counter.

---

### Hold

When `pc_write` is deasserted,

```
PC ← PC
```

The current Program Counter value is preserved.

---

# 5. RTL Architecture

```
                  +-------------------------+
                  |     Program Counter     |
                  |                         |
      pc_next --->|                         |-----> pc
                  |                         |
     pc_write --->|                         |
                  |                         |
          rst --->|                         |
                  +-------------------------+
                         ^
                         |
                        clk
```

The Program Counter is implemented as a single sequential register using an `always @(posedge clk)` block.

---

# 6. Design Decisions

## External Next PC Logic

The Program Counter does not compute `PC + 4`.

Instead, the next address is generated by dedicated datapath logic.

This separation of responsibilities improves modularity and allows future support for:

- Sequential execution
- Branch instructions
- Jump instructions
- Exception handling
- Pipeline control

without modifying the Program Counter itself.

---

## Write Enable

The `pc_write` signal enables or disables Program Counter updates.

Although a single-cycle processor updates the PC every instruction, this control signal is included to support future pipeline implementations where the PC may need to stall.

---

## Reset Vector

The reset value is obtained from `rv32i_params.vh` using

```
`RESET_VECTOR
```

This avoids hardcoded addresses and simplifies future architectural changes.

# 9. Conclusion

The Program Counter is implemented as a simple, reusable sequential register with a clean and extensible interface. The design is fully synthesizable and forms the foundation of the Instruction Fetch stage of the RV32I processor.
